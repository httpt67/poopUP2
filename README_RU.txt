poopUP Telegram Mini App — файлы

Для GitHub Pages загрузите в корень репозитория: index.html, style.css, app.js.
После загрузки включите Settings → Pages → Deploy from a branch → main → /(root).

Bot-файлы (bot.py, requirements.txt, .env.example) нужны только для запуска Telegram-бота отдельно.
Секрет BOT_TOKEN не публикуйте и не загружайте в GitHub.

В текущей версии игровой прогресс хранится в localStorage браузера; это прототип, не серверная игра.
